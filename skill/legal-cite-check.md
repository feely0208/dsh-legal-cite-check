# 深鲸引用核验（dsh-legal-cite-check）

**什么时候用**：文书定稿前、AI 生成的法律文书发出前，核验里面的《法名》第 N 条、法释文号、案号是否可靠。用户说「引用核验」「查法条真假」「有没有引错法条」「AI 写的案例是真的吗」，就用这个。

```bash
<cli> <文书.md|目录> [--strict] [--json] [--out 输出目录]
<cli> --demo
```

## 它核验什么

| 类型 | 能核验的 | 核验不了的 |
|---|---|---|
| 《法名》第 N 条 | 法名是否已废止/被取代；条号是否超出条文总数；条文是否整体重排；是否尚未生效 | 这条法是否适用于本案 |
| 法释〔年〕N 号 | 是否已被新解释取代 | 文号内容是否与引用观点一致 |
| 案号 | 只做格式识别 | 案件是否真实存在（一律标 UNVERIFIED） |

## 状态怎么读

| 状态 | 级别 | 处理 |
|---|---|---|
| `OUTDATED` | material | **必须改**。按 `replaced_by` 改引新法，条号也要重查 |
| `OUT_OF_RANGE` | material | **必须改**。多半是模型编的条号，回原文找正确条号 |
| `RENUMBERED` / `PENDING` / `UNKNOWN` | warn | 人工核对；`UNKNOWN` 是索引未收录，不是「通过」 |
| `UNVERIFIED` | info | 案号/文号需到裁判文书网、最高法官网核对 |
| `OK` | ok | 只说明「这条存在」，不说明「这条有效/适用」 |

## 产物

- `citations.csv`：逐条核验表（UTF-8 BOM，Excel 可直接开）
- `citations.md`：汇总 + 必须处理项 + 需人工核验项 + 逐条明细

## 纪律

1. 只对随包离线索引负责，不联网、不调用模型。
2. 核验不了就写「需人工核验」，不猜条号、不编正确改法。
3. 报告结论必须带上「通过 ≠ 适用」，正式提交前由承办律师核对 flk.npc.gov.cn 原文。
4. 只读 `.md` / `.txt`；`.docx` 请先转文本。
